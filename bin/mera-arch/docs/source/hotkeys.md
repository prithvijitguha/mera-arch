# Mera-Arch Hotkeys

## Window Management

  ------------------------------------------------
  Hotkey                 Action
  ---------------------- -------------------------
  `Super + w`            Close window

  `Super + ↑`            Maximize window

  `Super + h`            Minimize window

  `Super + Backspace`    Resize window

  `Super + t`            Check window layout

`Shift + F11`          Fullscreen
  ------------------------------------------------

## Window Navigation

  ----------------------------------------------------------
  Hotkey                 Action
  ---------------------- -----------------------------------
  `Super + h`      Shift focus to window on left

  `Super + l`      Shift focus to window on right

  `Super + j`      Shift focus to window below

  `Super + k`      Shift focus to window above

  ----------------------------------------------------------
